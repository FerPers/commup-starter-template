# CommUP Vector Pack — Option B

Paquete vectorial inicial para uso en app, Figma, web y documentación.

## Contenido

- `/logo/commup-symbol-option-b.svg`: isotipo tipo smart tag + QR/NFC + check.
- `/logo/commup-logo-option-b-horizontal.svg`: logo horizontal.
- `/logo/commup-logo-option-b-stacked.svg`: logo vertical/staked.
- `/icons/*.svg`: 12 iconos modulares.
- `commup-icons-sprite.svg`: sprite SVG para frontend.

## Paleta base

- Deep Navy: `#0B1D3A`
- Petroleum Blue: `#005A8D`
- Teal: `#00B5A8`
- Industrial Orange: `#FF8A00`
- Steel Gray: `#64707C`
- Light Gray: `#E9EDF1`

## Recomendación de uso

- Usar navy como color principal de trazo.
- Usar teal para estados positivos, trazabilidad, scan, ejecución y validación.
- Usar orange de forma limitada para advertencias, Punch List, timestamps o criticidad media.
- Evitar rojo como color de marca; reservarlo para alarmas, bloqueo crítico o Punch Category A.

## Nota

Estos SVG son una primera base visual editable. Conviene refinarlos luego en Figma para grid óptico, variantes 16/20/24/32 px, estados hover, disabled, active y dark mode.
